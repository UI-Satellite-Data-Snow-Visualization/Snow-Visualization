# Setting Up NASA Earthdata Access for VIIRS & MODIS

This guide explains how to create a NASA Earthdata account and configure an authentication token for accessing **VIIRS** and **MODIS** satellite data.

## 1. Create a NASA Earthdata Account

Navigate to the NASA Earthdata Login page:

https://urs.earthdata.nasa.gov/

Select **Register for a Profile** and complete the account registration process.

After registering, confirm your account using the verification email sent by NASA.

> **Screenshot:** Earthdata Login / Registration page  
>
> `![Earthdata Login](images/earthdata-login.png)`

---

## 2. Open Your Earthdata Profile

Once logged in, open your account profile.

Navigate to:

**My Profile → Generate Token**

> **Screenshot:** My Profile page showing the Generate Token option  
>
> `![Earthdata Profile](images/earthdata-profile.png)`

---

## 3. Generate an Earthdata Token

On the **Generate Token** page, select the option to generate a new authentication token.

NASA will display your Earthdata token.

> **Screenshot:** Generate Token page  
>
> `![Generate Earthdata Token](images/generate-token.png)`

> **Important:** Treat your Earthdata token like a password. Do **not** commit the token to GitHub, include it in screenshots, or place it directly inside source code.

---

## 4. Open a Terminal

Open a terminal on your computer.

On Windows, this can be:

- **PowerShell**
- **Windows Terminal**
- A terminal inside **VS Code**

For this guide, we will use **PowerShell**.

> **Screenshot:** PowerShell or Windows Terminal  
>
> `![PowerShell](images/powershell.png)`

---

## 5. Copy Your Earthdata Token

Return to the Earthdata **Generate Token** page and copy the generated token.

Do not share this token or include it in project documentation.

---

## 6. Set the Earthdata Token

In **PowerShell**, enter:

```powershell
$env:EARTHDATA_TOKEN = "your_pasted_token_here"
```

Replace `your_pasted_token_here` with the token generated by NASA.

For example:

```powershell
$env:EARTHDATA_TOKEN = "YOUR_TOKEN"
```

Press **Enter**.

> **Screenshot:** PowerShell showing the environment-variable command  
>
> **Do not include your real token in the screenshot.**
>
> `![Set Earthdata Token](images/set-earthdata-token.png)`

---

## 7. Verify the Environment Variable

You can verify that the environment variable exists with:

```powershell
$env:EARTHDATA_TOKEN
```

PowerShell should return your token.

> **Security Note:** This command prints the complete token to the screen. Avoid using it while screen sharing, recording, or taking screenshots.

Your environment is now configured to authenticate with NASA Earthdata services using the `EARTHDATA_TOKEN` environment variable.
